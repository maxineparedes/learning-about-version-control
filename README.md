# Learning About Version Control

**Author:** Maxine Paredes

Solving merge conflicts takes conscious effort, but I can do it!

I really appreciate that version control is so flexible and is able to address a lot of the problems that occur when collaborating on code with multiple people.

Personally, I have found this flexibility quite difficult to navigate because even though you can fix version control issues in many different ways, I'm hesitant to try things because I don't want to this to have downstream impacts on my collaborators.
